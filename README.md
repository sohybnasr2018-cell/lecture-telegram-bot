# 🎓 بوت تفريغ وتلخيص المحاضرات الذكي (Smart Lecture Telegram Bot)

بوت تيليجرام أكاديمي متكامل واحترافي، مبني بنفس واجهة وتجربة البوت الموضحة في الصور تماماً، ومجاني بنسبة 100% باستخدام **Google Gemini API** و **GrammY** و **Puppeteer**.

---

## ✨ المميزات الرئيسية للمشروع

### 1. مطابقة تامة لواجهات البوت في الصور (Pixel-Perfect UI)
* **الشاشة الرئيسية (الصورة 1):**
  * رسالة ترحيب مخصصة باسم المستخدم (`أهلاً د. {اسم الطالب}! 🖐️`).
  * لوحة مفاتيح رئيسية تفاعلية:
    * `🎙️ تفريغ محاضرة`
    * `🖼️ صور على المحاضرة` | `🤝 شارك البوت`
    * `⚙️ الإعدادات`
* **شاشة تفريغ المحاضرة (الصورة 2):**
  * إرشادات إرسال الريكورد أو عمل فورورد (Forward) من أي قناة أو جروب.
  * زر العودة `🔙 القائمة الرئيسية`.

---

### 2. الميزات الإضافية المتقدمة المطلوبة

#### 🎯 أ. نمط الكويز التفاعلي (Interactive Quiz Mode)
* بعد معالجة الريكورد أو استخراج الـ PDF، يضغط الطالب على **`❓ كويز تفاعلي`**.
* يرسل البوت أسئلة اختيار من متعدد رسمية داخل التيليجرام (**Telegram Native Quiz Polls**).
* عند اختيار الإجابة، تظهر للطالب النتيجة فوراً مع احتفال (Confetti) وشرح فوري لسبب صحة الإجابة مستخرجاً من كلام الدكتور!

#### 🗂️ ب. توليد فلاش كاردز أنكي (Anki Deck Generator)
* بنقرة واحدة على **`🗂️ بطاقات أنكي (.apkg)`**، يقوم البوت بإنشاء حزمة بطاقات حقيقية بصيغة **`.apkg`**.
* الطالب يضغط على الملف في هاتفه أو حاسوبه ليفتح مباشرة في تطبيق **Anki / AnkiDroid / AnkiMobile** ويتم استيراده تلقائياً!
* يتضمن أيضاً ملف نصي بديل جاهز للاستيراد السريع.

#### 💬 ج. اسأل المحاضرة (Chat with Lecture بالدقيقة والثانية)
* يمكن للطالب تفعيل وضع **`💬 اسأل المحاضرة`** وطرح أي سؤال نصياً أو عبر رسالة صوتية (Voice Note).
* يقوم البوت بالبحث في التسجيل الصوتي وفهرس الدقائق، ثم يجيب:
  * ⏱️ **التوقيت في التسجيل:** `[MM:SS]` (مثال: `[14:25 - 15:10]`).
  * 💡 **الشرح والإجابة:** شرح كامل ومبسط للإجابة.
  * 📢 **نص ما قاله الدكتور:** اقتباس لما ذكره المحاضر نصاً وتنبيهه حولها في الامتحان.

#### 🌐 د. تخصيص لغة مذكرة الـ PDF (عربي / English / Mix)
يمكن للطالب اختيار اللغة من قائمة **`⚙️ الإعدادات`** أو اختيارها مباشرة قبل توليد الـ PDF:
1. **🇪🇬 عربي:** شرح فصيح ومصطلحات معربة.
2. **🇬🇧 English:** مذكرة أكاديمية كاملة بالإنجليزية.
3. **🔄 مكس (عربي + إنجليزي):** الأسلوب الأكثر طلباً في كليات الطب والهندسة والصيدلة والحاسبات (شرح بالعربية مع الحفاظ على المصطلحات العلمية والطبية بالإنجليزية، مع تنسيق محاذاة RTL و LTR متناغم).

#### 🖼️ هـ. صور ومخططات توضيحية داخل الـ PDF
* إمكانية تفعيل أو تعطيل إضافة المخططات الانسيابية (Flowcharts) والرسوم التوضيحية داخل المذكرة بضغطة زر.

## 📎 دعم الملفات الكبيرة (حتى 300 MB و 2 ساعة و 55 دقيقة)

* **الوضع الافتراضي (سيرفر تيليجرام السحابي):**
  يدعم استلام ملفات الصوت حتى **20 ميجابايت** مباشرة بدون أي إعدادات إضافية.
* **لدعم ملفات حتى 300 ميجابايت و 2 جيجابايت مجاناً:**
  توفر تيليجرام خادم Bot API مجاني ومفتوح المصدر (`telegram-bot-api`). يمكنك تشغيله على جهازك أو سيرفرك بضغطة واحدة باستخدام Docker:
  ```bash
  docker run -d -p 8081:8081 --name=tg-bot-api \
    -e TELEGRAM_API_ID=your_api_id \
    -e TELEGRAM_API_HASH=your_api_hash \
    aiogram/telegram-bot-api:latest
  ```
  ثم وضع `TELEGRAM_API_ROOT=http://localhost:8081` في ملف `.env`. عندها سيتعامل البوت مع ملفات تصل حتى **2000 MB (2 GB)** بكل سلاسة وبالمجان!

## 🚀 دليل التثبيت والتشغيل السريع

### 1. المتطلبات الأساسية
* مثبت على جهازك بيئة **Node.js** (الإصدار 18 أو أحدث).

### 2. الحصول على المفاتيح المجانية
1. **توكن التيليجرام (Telegram Bot Token):**
   * افتح تيليجرام وابحث عن `@BotFather`.
   * أرسل الأمر `/newbot`، اختر اسماً واسم مستخدم للبوت.
   * انسخ التوكن (Token).
2. **مفتاح Gemini API المجاني:**
   * افتح [Google AI Studio](https://aistudio.google.com/).
   * اضغط على **Get API Key** ثم **Create API key**.
   * انسخ المفتاح.

### 3. إعداد ملف البيئة `.env`
قم بإنشاء ملف باسم `.env` بجوار `.env.example` وضع فيه المفاتيح:
```env
TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRstuVWXyz
GEMINI_API_KEY=AIzaSyDxxxxxxxxxxxxxxxxxxxxxxxxx
GEMINI_MODEL=gemini-2.5-flash
TEMP_DIR=./temp
```

### 4. تثبيت المكتبات وتشغيل البوت
افتح موجه الأوامر (Terminal / PowerShell) في مجلد البوت واكتب:
```bash
# تثبيت التبعيات (إذا لم تكن مثبتة)
npm install

# تشغيل البوت
npm start
```

### 5. تشغيل وضع التطوير التلقائي (Auto-reload)
```bash
npm run dev
```

### 6. تشغيل الاختبارات الشاملة (Verification Tests)
```bash
npm test
```

## 📱 تجربة الطالب داخل البوت بالتفصيل

1. يرسل الطالب `/start` فيرى واجهة الترحيب الأنيقة وأزرار القائمة المطابقة للصورة الأولى.
2. يضغط الطالب على **`🎙️ تفريغ محاضرة`** فتظهر له تعليمات الإرسال المطابقة للصورة الثانية.
3. يقوم الطالب بإرسال أو عمل Forward لأي تسجيل صوتي أو فويس نوت.
4. يرسل البوت رسائل حالة تفاعلية حية تبلغه بمراحل المعالجة.
5. بعد انتهاء المعالجة، تظهر لوحة تحكم متكاملة تحتوي على:
   * **📄 تنزيل مذكرة PDF:** مذكرة منسقة بأعلى درجات الجمال والترتيب الأكاديمي.
   * **❓ كويز تفاعلي:** 5 أسئلة بنظام Telegram Poll Quiz مع تقييم واحتفال فوري.
   * **🗂️ بطاقات أنكي:** ملف `.apkg` قابل للفتح المباشر في Anki.
   * **💬 اسأل المحاضرة:** يسأل الطالب أي سؤال صوتياً أو كتابياً، فيرد البوت بالدقيقة والثانية!
   * **🎯 أسئلة الدكتور:** استعراض أهم ما شدد عليه الدكتور للامتحان.
   * **🌐 لغة المذكرة:** إمكانية إعادة استخراج المذكرة بلغة مختلفة (عربي / إنجليزي / مكس).
